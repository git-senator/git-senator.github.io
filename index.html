ОБО МНЕ

Привет. Я SENATOR — специалист по кибербезопасности и AI-инженер с фокусом на red team операциях и тестировании систем на основе больших языковых моделей.

Работаю на стыке двух дисциплин: пентест веб-приложений и систематическое тестирование ИИ-продуктов. Нахожу слабые места там, где другие видят только рабочий функционал.

ПОРТФОЛИО

Система трёхуровневой оценки ИИ-продуктов // AI EVALUATION
Разработка комплексной системы тестирования LLM-ассистента. Система охватывает три уровня: автоматические unit-тесты (assertion-based, аналог pytest), оценку человеком и LLM-критиком с трассировкой через LangSmith, и A/B-эксперименты с реальными пользователями. Включает кастомные инструменты разметки данных (Shiny for Python) и дашборды мониторинга в Metabase. Тесты покрывают сотни сценариев взаимодействия пользователей с AI-системой.
Level 1: Unit Tests (assertions) Level 2: Human + LLM-as-Judge Level 3: A/B Testing LangSmith / LangChain Metabase Dashboard Shiny for Python
Синтетическая генерация тест-кейсов для LLM // DATA SYNTHESIS
Методология и инструментарий для автоматической генерации синтетических тестовых данных с использованием LLM. Промпты генерируют разнообразные пользовательские сценарии взаимодействия с AI-системами. Автоматическая фильтрация некачественных примеров через assertions и модель-критик. Результирующие данные используются как для unit-тестов, так и для fine-tuning.
LLM-as-Generator Assertion Filtering Fine-tuning Dataset Quality Control Pipeline
Web Application Penetration Testing // RED TEAM

Тестирование аутентификации, авторизации, API-эндпоинтов, обработки пользовательского ввода. Полная отчётность с PoC и рекомендациями по устранению.
